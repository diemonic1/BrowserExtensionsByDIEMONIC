Оставляет только одну вкладку для заданных URL: как только открывается новая вкладка с таким URL, все старые вкладки с ним автоматически закрываются.

- Список URL задаётся в настройках (страница настроек и попап по клику на иконку — это одна и та же страница).
  - `github.com` — весь сайт вместе с поддоменами.
  - `github.com/user` — только этот путь и всё, что глубже.
  - `*` — любые символы, например `*.google.com/maps*`.
- Галочка «Only one new tab page» — считает дубликатами друг друга страницы новой вкладки браузеров на Chromium (`chrome://newtab`, `edge://newtab`, `browser://newtab`, `vivaldi://startpage`, `opera://startpage`, …) и вкладки без URL (`about:blank`).
- Кнопка «Close duplicates now» — разово закрывает уже открытые дубликаты, оставляя последнюю использованную вкладку.

Одна и та же папка `code` работает и в Chrome (и других Chromium), и в Firefox 121+ без правок.

Установка:
- Chrome: `chrome://extensions` → режим разработчика → «Загрузить распакованное» → папка `code`.
- Firefox: `about:debugging#/runtime/this-firefox` → «Загрузить временное дополнение» → файл `code/manifest.json`.
